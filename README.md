# 草蛇灰线 greystrider

草蛇灰线是一个面向自由行用户的多地点路线规划 Demo。用户输入城市、起点、终点和候选地点后，可先在真实地图上查看地点分布并二次筛选，再生成串联所选地点的分段路线。

## 产品背景

旅行规划常分散在内容平台和地图工具中：用户收集地点后，还要逐个搜索、判断相对距离、取舍交通不便的地点，并反复查看下一段路线。草蛇灰线把这个过程整合为“地点录入 - 地图筛选 - 路线生成 - 分段查看”的连续流程。

## 核心功能

- 搜索并逐个添加候选地点，下拉结果按相关性排列。
- 固定起点和终点，在地图上选择或取消候选地点。
- 使用最近邻启发式方法生成地点访问顺序。
- 调用高德地图路线服务生成步行、骑行、公交和地铁方案。
- 路线默认收起，展开某一段时只在地图上高亮该段。
- 公交/地铁路线展示上下车站、线路方向、乘坐站数及换乘节点。

## 运行方式

项目为原生 HTML、CSS、JavaScript 页面，可使用任意静态服务器运行。例如：

```bash
python -m http.server 4173
```

打开 `http://127.0.0.1:4173/`。未配置高德地图时，页面会进入离线演示模式。

## 地图配置与安全

仓库中的 `amap-config.js` 只保留公开运行配置，未包含任何真实 Key 或安全密钥。线上版本通过 Vercel Functions 提供两层保护：

- `/api/amap-config` 在运行时返回受域名限制的 Web 端 JS Key。
- `/_AMapService` 将地图服务请求转发到高德，并仅在服务端附加 `securityJsCode`。

部署到 Vercel 时需要配置以下环境变量：

```text
AMAP_JS_API_KEY
AMAP_SECURITY_JS_CODE
```

请在高德开放平台将 JS Key 的域名白名单限制为正式 Vercel 域名，并根据需要设置调用配额。

不要把真实凭据提交到 Git、README、Issue、截图或公开部署日志中。如果凭据曾经进入公开仓库，请立即在高德开放平台轮换。

## Vercel 部署

1. 在 Vercel 导入本 GitHub 仓库。
2. Framework Preset 选择 `Other`，根目录保持仓库根目录。
3. 在项目环境变量中添加上述两个变量，并勾选 Production。
4. 部署完成后，将正式域名添加到高德 Key 的域名白名单，再重新部署一次。
